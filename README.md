# Shiroko MD Portfolio

Portofolio landing page untuk Shiroko MD, dibuat dengan Astro.

## Jalankan lokal

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

Catatan: avatar dan thumbnail menggunakan URL gambar eksternal yang diberikan pemilik situs, sehingga gambar akan tampil selama URL tersebut dapat diakses dari browser pengunjung.
